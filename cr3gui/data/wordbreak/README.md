# Word lists for line breaking

Some scripts are written without spaces between words, so the Unicode line
breaking algorithm (libunibreak) finds no place to wrap lines inside a run
of text. For them, crengine uses a word list to find word boundaries.

## th_words.txt (Thai)

Used by `crengine/src/thaiwordbreak.cpp`.

- Source: PyThaiNLP, `pythainlp/corpus/words_th.txt`
  <https://github.com/PyThaiNLP/pythainlp/blob/dev/pythainlp/corpus/words_th.txt>
  (commit c598a2ad96a64cbcd4c6e04aa71415a40e408871)
- License: Creative Commons Zero 1.0 Universal (CC0-1.0), see
  <https://github.com/PyThaiNLP/pythainlp/blob/dev/pythainlp/corpus/corpus_license.md>

Format: UTF-8, one word per line. Lines that are not made only of Thai
letters, vowels and tone marks (entries with spaces, dots, digits...) are
ignored, as they could never match inside a run of Thai letters.

## th_weak_words.txt (Thai)

Short words of `th_words.txt` that are rare as words, and mostly met as
syllables of names and transliterated foreign words (นิ, ริ, จู, ไอ...):
they are used to segment text, but a line break is never allowed on either
side of them. Generated by `tools/gen_thai_weak_words.py` from PyThaiNLP
`pythainlp/corpus/tnc_freq.txt` (Thai National Corpus word frequencies,
CC0-1.0).

## User words

Users can add their own words (same format) in
`settings/user-thai-words.txt`: this is the way to fix a name or a
foreign word that gets broken in the middle (ยูโดร่า, สปาร์กกี้...).
